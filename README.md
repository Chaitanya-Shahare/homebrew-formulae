# homebrew-formulae

Homebrew tap for Chaitanya Shahare's tools.

| Package | Install | What it is |
|---|---|---|
| [ytspot](https://github.com/Chaitanya-Shahare/ytspot) | `brew install --cask chaitanya-shahare/formulae/ytspot` | YouTube Music for Mac with a Spotify-style UI |
| [spotify-notifier](https://github.com/Chaitanya-Shahare/spotify-notifier) | `brew install chaitanya-shahare/formulae/spotify-notifier` | Notifications for Spotify song changes |
| [block-site](https://github.com/Chaitanya-Shahare/block-site) | `brew install chaitanya-shahare/formulae/block-site` | Block and unblock websites via `/etc/hosts` |
